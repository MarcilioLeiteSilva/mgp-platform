# MGP Android SDK (Kotlin)

Módulo dedicado ao SDK nativo Android da **Mobile Growth Platform**.

## Recursos Previstos (Fases 04/05 do Roadmap Global)
- **`MgpCore`**: Inicialização singleton e envio de telemetria.
- **`MgpBannerView`**: Componente de banner com controle estrito de viewability.
- **`MgpNativeAd`**: Renderização integrada à interface nativa do aplicativo.
- **`MgpInterstitialAd`**: Anúncios de tela cheia com pré-carregamento.

Compatibilidade mínima: Android 7.0+ (API Level 24).
